- 好像遇到一点自己不想做的事,就会很低能量,想要拖延,想要逃离,开始责怪环境;如果事不顺的事,如果我能全心力去解决还行,解决了,我会很轻松很开心;但是如果还有其他事情排着队,感觉就很沉重,只想先放下当下,想给自己时间去调整
