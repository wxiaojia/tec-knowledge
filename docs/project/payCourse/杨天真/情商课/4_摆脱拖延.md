# 【公式4】摆脱拖延：掌握优先级法，用自己舒服的方式做到自律

## PART1 自律的本质：是对精力的分配

根据自己的优先级排序：比如健康>学习>工作

自律=对精力的分配=重点关注+及时放弃

情商真言：
能量的耗损不来自不自律,而来自什么都想要结果什么都没做好

## PART2 自律的定义 
自律是要在对的时间花对的精力
想自律，先放弃

## PART3 如何找到自己重点关注和及时放弃的对象
1.得出你短期确定想要的1-3样东西
·不限数量,写下愿望
·根据想要的程度做比较
·根据条件作比较

2.得出你长期绝对不要的东西
3.根据前两点,得出你当下的必要行动
4.其他的一切,都是你可以放弃的东西

没有对错，只有选择
