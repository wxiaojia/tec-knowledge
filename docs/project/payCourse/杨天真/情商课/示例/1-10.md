## 二、用AEIOU美好时光日志，了解我们的能量
就是在日常生活中,随时记录以下几点
1.你正在做的事情
2.你当下的能量值
3.什么因素影响了你的能量值

A:活动(Activity)        你到底在做什么?  这是一个结构性的活动还是一个非结构性的活动? 你是团队的领导者还是参与者?
E:环境(Environment )    在会议和户外你产生的感觉是不同的,注意你所在的环境它是怎样的?给你什么样的感觉呢?
I：互动(Interaction)    你和人或者机器有怎样的互动?是陌生的还是熟悉的?是正式的还是非正式的?
O: 物体(0bject )        你在使用物体或者设备吗? 这些事物会提升你的能量吗?
U：用户(User)           活动中还有其他人吗? 他们扮演了什么角色? 带来了正面还是负面影响?

## 四、回馈分析法：
在做一件事之前先记录下自己对结果的预期等时间到了对比一下
看自己做得是比预期好还是比预期差
从而判断自己是否适合做这件事

SMART:
S:具体(Specific): “3个月之后,我能从单兵作战到带出1个人
M:可衡量(Measurable) “3个月之后, 我能独立负责用户调研的工作, 独立负责的意思是,主管在这项工作上,辅导我的时间不超过1小时
这才是一个可衡量的预测
A:可实现(Attainable)
R:相关性(Relevant)
T:有时限(Time-bound)

## 十、升级微习惯配方，养成运动好习惯
！！！用锚点时刻和庆祝，来巩固我们的微习惯

![升级微习惯](../assets/image10.png)

这个方法来自《福格行为模型》
它的的巧妙之处在于把我们已经在做的行为当成提示,促进我们培养新习惯

那么你就可以把你的微习惯配方
刷牙 → 2个俯卧撑 变成 把牙刷放在牙缸里一 2个俯卧撑

用“最后动作”来优化锚点时刻

洗澡 → 擦干身体后挂好浴巾
