📌7.提升表达力的训练方法
1.朗读法
每天花10mih朗读一篇新闻类文章(强国里多的很)
2.对镜练习法
每天对着镜子说一段鼓励自己的话你会从容表达，更加自信
3.背诵法
背诵自己很有共鸣、喜欢的文字慢慢积累语言素材库
4:绕回令训练法
每天读5遍绕回令训练口齿的伶俐，锻炼发音的准确性
5.复述法
看完一篇文章、一段故事，或把今天的趣事
用自己的语言说给家人听，锻炼总结概括能力
6.录制视频法当自己表达时
可以拍视频记录下来
从视频中纠正不流畅的地方帮助改善表达中的小问题~
