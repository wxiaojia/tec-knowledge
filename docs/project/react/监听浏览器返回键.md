在 React 中，要监听浏览器左上角的返回按钮并阻止其跳转操作，可以使用 window 的 popstate 事件，结合 react-router-dom 的 useNavigate。这样可以检测到用户点击返回按钮的行为，然后阻止默认跳转并执行自定义逻辑。

```js
import React, { useEffect } from 'react';
import { useNavigate } from 'react-router-dom';

function MyComponent() {
    const navigate = useNavigate();

    useEffect(() => {
        // 定义 popstate 事件处理函数
        const handlePopState = (event) => {
            event.preventDefault();
            // 执行自定义逻辑，比如显示确认对话框
            const userConfirmed = window.confirm("确定要返回吗？");

            if (userConfirmed) {
                // 如果用户确认，则执行跳转
                navigate(-1); // 后退一步
            } else {
                // 如果用户取消，阻止跳转
                window.history.pushState(null, "", window.location.href);
            }
        };

        // 添加事件监听器
        window.addEventListener('popstate', handlePopState);

        // 在组件卸载时移除监听器
        return () => {
            window.removeEventListener('popstate', handlePopState);
        };
    }, [navigate]);

    return (
        <div>
            <h1>这是一个示例组件</h1>
        </div>
    );
}

export default MyComponent;
```
代码说明
window.addEventListener('popstate', handlePopState);：监听 popstate 事件，检测用户是否点击了返回按钮或调用了 history.back()。
event.preventDefault();：阻止浏览器默认的返回操作。
window.confirm：弹出一个确认对话框，询问用户是否确定要返回。可以根据需求自定义行为。
navigate(-1);：当用户确认时，手动调用 navigate(-1) 来实现后退操作。
window.history.pushState：如果用户取消返回操作，则将当前页面的状态重新压入历史记录，阻止页面导航。
注意事项
popstate 事件不支持在页面初次加载时触发，所以只适用于前进和后退的操作。
window.history.pushState(null, "", window.location.href); 的目的是将当前页面重新压入历史记录中，以防止用户点击返回后会自动跳转。这种方式在需要严格控制导航行为的场景中很有效。
