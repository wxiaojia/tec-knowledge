### update-pkg
更新依赖版本；update package.json dependencies versions
内部执行命令 
```bash
execa.execa('npx', ['ncu',  '--deep', '-u'], { stdio: 'inherit' })
```

ncu : npm-check-update 更新项目中所有依赖版本

第一个参数： 'npx' 表示要执行的命令是 npx，这是一个 Node.js 工具，用于运行本地或远程的 npm 包。
第二个参数：它代表了传递给 npx 的参数。这些参数将依次传递给 ncu（npm-check-updates）：
--deep：这个选项表示递归检查子目录中的 package.json 文件。这对于包含多个子项目（例如 monorepo 结构）或多个 package.json 文件的项目非常有用。
-u：表示更新所有的依赖包到最新版本（upgrade），即将 package.json 中的依赖版本更新为最新版本。
第三个参数：
stdio: 'inherit' 配置项确保子进程的标准输入输出（stdin、stdout 和 stderr）被继承，这样命令的输出将直接显示在主进程的控制台上，就像在终端中直接运行一样。

该命令用处：
- 在项目初始化或构建脚本中自动检查和更新依赖。
- 用于 monorepo 项目中，批量更新各个子包的依赖版本。
- 开发者想快速升级所有依赖包，而不手动更新 package.json。
