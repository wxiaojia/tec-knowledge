## 方法 1：使用 webpack-plugin-istanbul 和模拟运行
通过 Webpack 插件注入代码覆盖率工具（如 Istanbul），然后运行项目，模拟用户操作来触发代码路径。

步骤
安装依赖

```js
npm install --save-dev webpack-plugin-istanbul
npm install --save-dev nyc
```

配置 Webpack 修改 Webpack 配置文件 webpack.config.js：

```javascript
const path = require('path');
const IstanbulPlugin = require('webpack-plugin-istanbul');

module.exports = {
  entry: './src/index.js',
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
  },
  module: {
    rules: [
      {
        test: /\.js$/,
        exclude: /node_modules/,
        loader: 'babel-loader',
      },
    ],
  },
  plugins: [
    new IstanbulPlugin({
      exclude: ['node_modules'],
    }),
  ],
};
```
运行项目

启动项目后，手动操作应用程序的页面，尽可能触发更多的逻辑代码。
例如，运行开发服务器：

```bash
npm run start
```
收集覆盖率数据

使用 nyc 或其他工具，生成覆盖率报告。运行以下命令：
```bash
nyc instrument ./src ./instrumented-src
```
查看报告 在运行应用时，代码覆盖率将被记录。你可以在 coverage/ 目录中查看覆盖率报告。

## 方法 2：通过 Puppeteer 或 Cypress 自动触发页面操作
使用浏览器自动化工具（如 Puppeteer 或 Cypress）模拟用户操作来覆盖代码路径。

步骤
安装 Puppeteer

```bash
npm install --save-dev puppeteer nyc
```
配置 Puppeteer 脚本 创建一个自动化脚本，例如 run-puppeteer.js：

```javascript
const puppeteer = require('puppeteer');

(async () => {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();

  await page.goto('http://localhost:3000'); // 替换为你的本地开发地址
  await page.click('#nav-about'); // 模拟点击导航到 About 页面
  await page.click('#nav-contact'); // 模拟点击导航到 Contact 页面
  
  await browser.close();
})();
```
运行脚本

启动本地开发服务器：
```bash
npm run start
```
执行 Puppeteer 脚本：
```bash
node run-puppeteer.js

```
收集覆盖率 配置 nyc 和 Istanbul，生成覆盖率报告。

## 方法 3：动态注入覆盖率工具（React DevTools + Istanbul）
步骤
安装覆盖率依赖

```bash
npm install --save-dev babel-plugin-istanbul nyc
```
配置 Babel 在 .babelrc 文件中启用 babel-plugin-istanbul 插件：

```json
{
  "presets": ["@babel/preset-react"],
  "env": {
    "test": {
      "plugins": ["istanbul"]
    }
  }
}```
运行开发服务器

通过 npm start 启动项目。
使用应用的功能，代码路径将被记录。
生成报告 配置 nyc 来生成 HTML 报告：

```bash
nyc report --reporter=html
```
