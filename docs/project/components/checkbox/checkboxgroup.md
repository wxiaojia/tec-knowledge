## 1、组件的功能；
- 封装全选hook   ✔
- 封装含全选组件
    - 反选功能 selectAnti，默认文字：反选 ✔
    - 全选功能 selectAll，默认文字：全选 - （进度：06周四，默认了全选, 07周五，可传参；10周一，全选文字可传参，默认全选）✔
    - 设置最大值，如10个数据，最大勾选5个，等于5个时，其他复选框不可选，小于5时都可选 max，没有默认就不限制 ✔
    - 方向设置 横向纵向 默认纵向  ✔

## 2、组件接收的数据；
- value 绑定值
- selectAll 是否全选
- allSelectText 全选文字 
- selectInverse 是否反选
- max 选择最大值
- options 列表
- defaultValue 默认选中
- direction 排版方向

## 3、组件自身维护的状态；
- options 接收的数据需要处理，处理成必备value label的对象
- getClass 类集合
- indeterminate 全选按钮的展示状态
- isInverseSelect 是否反选

- group发生变化
- 全选操作
- 反选操作
