## 1、功能
- 带搜索按钮组件	
- 支持悬浮展示比较多内容的提示信息
- 添加前缀，开放插槽	

## 2、接收的数据
- value 输入框值
- width 搜索框长度
- getPopupContainer 默认g-search-input
- trigger 触发机制：hover|click
- overlayStyle 弹出的style
- placement 悬浮位置，默认底下，悬浮宽度撑开整个框
- placeholder 搜索框占位符，默认 请输入
- content 悬浮内内容提示
- allowClear 是否清除按钮
